# Iris MLOps Pipeline

![CI](https://github.com/ambi1999/iris-mlops-pipeline/actions/workflows/ci.yml/badge.svg)

An end-to-end MLOps pipeline for an Iris flower classifier: model training with an
accuracy quality gate, a FastAPI prediction service, automated tests, Docker
packaging, and CI with GitHub Actions. Includes two self-contained notebooks
that teach MLOps and DevOps concepts to beginners.

## Tech stack

Python 3.13 · uv · scikit-learn · FastAPI · pytest · Docker · GitHub Actions · Dependabot · Jupyter

## Project structure

| File | Purpose |
|------|---------|
| `train.py` | Trains, evaluates and saves the model; fails if accuracy < 85% |
| `app.py` | FastAPI web service with `/health` and `/predict` |
| `test_app.py` | Automated tests (pytest) |
| `pyproject.toml` | Project dependencies, managed by uv |
| `uv.lock` | Exact version of every package (generated by uv; always commit it) |
| `.python-version` | The single source of truth for the Python version |
| `Dockerfile` | Packages the app and model into a container image |
| `.github/workflows/ci.yml` | CI pipeline: train → test → upload model → build image |
| `.github/dependabot.yml` | Weekly automated dependency-update pull requests |
| `notebooks/01_mlops_demo.ipynb` | 15–20 min MLOps walkthrough with explanations and exercises |
| `notebooks/02_devops_demo.ipynb` | 15–20 min DevOps walkthrough with explanations and exercises |
| `docs/getting-started.md` | Step-by-step setup guide with every command explained |

Every file is commented to explain what each command does.

## Setup

> **New to uv, Git or Docker?** Follow the [step-by-step guide](docs/getting-started.md). It explains every command and includes a troubleshooting section.

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then:

    uv sync

This installs Python 3.13 if needed, creates `.venv`, and installs the exact
versions from `uv.lock`.

## Run locally

    uv run python train.py
    uv run pytest -v
    uv run uvicorn app:app --reload

Open http://localhost:8000/docs to try the API in your browser.

## Run with Docker

    docker build -t iris-mlops-pipeline .
    docker run -p 8000:8000 iris-mlops-pipeline

## Run the published image

Every change that passes CI on `main` is automatically published to the
GitHub Container Registry. Run the latest version without cloning anything:

    docker run --rm -p 8000:8000 ghcr.io/ambi1999/iris-mlops-pipeline:latest

Each image is also tagged with the commit it was built from (for example
`sha-1a2b3c4`), so any version can be traced back to its code or rolled back.

## Useful uv commands

| Command | What it does |
|---------|--------------|
| `uv sync` | Create/update `.venv` to match `uv.lock` exactly |
| `uv add <package>` | Add an app dependency |
| `uv add --dev <package>` | Add a development-only tool |
| `uv lock --upgrade` | Upgrade all packages within the allowed ranges |
| `uv run <command>` | Run a command inside the project environment |

## Run in CI

Push to GitHub. The workflow in `.github/workflows/ci.yml` runs automatically;
watch it under the repo's **Actions** tab.
